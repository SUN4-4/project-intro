01 The idea

项目简介

机器人会执行任务，
但很少把经验留下来。

大多数机器人系统把每个任务当作一次性脚本：成功就结束，失败就重试。 能力没有沉淀，下一次遇到相似任务仍然从零开始。

RoboRSI 的核心是把任务、技能和策略放在同一棵树上。 long_horizon 负责任务族和阶段编排，atomic 负责边界清晰、结果可验证的原子任务，base 提供感知、运动、抓取、放置等可复用工具。

执行结束后，Reviewer 从 trace 中找到最早出错的节点；演化门禁在真实仿真任务上 验证提案，确认没有回退后才写入技能。成功路径可以固化为代码，也可以作为数据 训练策略。

02 Direction

核心能力

三个闭环：角色、技能、评测。

RoboRSI 不依赖某个单一模型或单一 benchmark；它把角色分工、技能复用和 评测裁决拆成可替换的层。

A

Multi-agent loop

Manager · Planner · Engineer · Reviewer

Manager 拆解目标，Planner 写出可执行计划，Engineer 驱动工具循环， Reviewer 独立诊断。Reviewer 只看可见 trace 和证据，避免执行者自报成功。

↗
B

Skill tree

任务、原子技能、基础能力

long_horizon / atomic / base 三层组织能力。稳定路径固化为代码，失败回到最早责任节点，执行数据可训练 learning-based policy。

C

Evaluation gate

由仿真器裁决，而不是自报

成功只由仿真器谓词在 episode 结束后裁定。frozen 模式关闭 跨 run 写回，evolve 模式才允许提案；eval-audit 可独立复核分数。

BM
Embodied Brain Task Goal Set

BM 是 RoboRSI 需要让具身大脑完成的任务目标集合。333 个任务从 BM-001 连续编号到 BM-333；成功视频、执行记录和技能都挂到对应 BM 编号下。
